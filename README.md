# ChessCheat

**An open-source chess cheat, made by me.**

ChessCheat is an open-source project developed to experiment with chess-related automation, board recognition and other features designed to interact with chess games.

The project was created with the intention of exploring different programming concepts, testing ideas and developing tools related to chess. Its source code is publicly available, allowing anyone to explore the implementation, study how it works, and contribute to its development.

## Features

ChessCheat is designed to provide a collection of features related to chess automation and board interaction.

Some of the planned and implemented functionalities include:

- **Board Detection:** A feature designed to identify and locate a chessboard on the screen.
- **Board Tracking:** A feature intended to follow the chessboard as it moves or changes position.
- **Chess Automation:** Experimental tools related to automating certain chess interactions.
- **Open Source:** Publicly available source code for transparency, learning and community contributions.
